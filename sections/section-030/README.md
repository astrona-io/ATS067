# Pull vs. Event-driven

This section covers pull vs. Event-driven. It develops event-Driven Triggers And Safe Repeated Actions through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains can include intermediate checkpoints before the final review.

## Learning Outcomes

- Explain why external events can initiate Kubernetes work.
- Distinguish event ingestion from task execution.
- Define dependency filters and trigger input mapping.
- Evaluate authentication, retries and idempotent side effects.
- Distinguish an event hint for authoritative retrieval from a one-time pushed deployment.
