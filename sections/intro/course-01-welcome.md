# Welcome To The Course

This course develops the official GitOps Patterns objectives for Certified GitOps Associate (CGOA). The certification uses a multiple-choice examination, so the course combines reading with hands-on work that shows each mechanism on a real cluster. It does not claim to simulate the examination.

Each section starts with its own introduction and learning outcomes. Each module has reading, a playground for free experiments, and a graded lab. Each section ends with a capstone lab that combines its modules and a quiz. A final domain quiz covers the whole course.

The four sections cover deployment and release patterns, progressive delivery with Argo Rollouts, pull-based and event-driven delivery with Argo CD and Argo Events, and architecture patterns such as agent placement, repository layout and state store management.

Read the explanations to identify the responsible component, the intended operation and the limits of each claim, then use the playground to watch it happen.
