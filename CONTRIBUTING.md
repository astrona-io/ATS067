# Contributing

Read CLAUDE.md before editing. Its shared prefix is copied from ATS015, while the custom portion describes ATS067: Certified GitOps Associate (CGOA), GitOps Patterns (20%), part of ATP013.

Preserve IDs, weights and existing track registration. Develop self-contained explanations with mechanisms, examples, prerequisites and failure reasoning. Start each section with an introduction and end each module with its own Summary. Keep technical Markdown draft until review.

Each module has a playground and a graded lab, each section has a capstone lab and a quiz, and the course has a final domain quiz. Labs and playgrounds are marked UNTESTED until someone runs them end to end. Do not claim executed results or invent command output. Quizzes are quiz.yaml files next to each section; keep question identities stable and give feedback for every option.

Use primary sources in SOURCES.md and record adaptation paths in AUTHORING.yaml. Run the preparation reading verifier and content-sync parser checks when changing structure. Review Markdown and questions for semantic correctness as well as structure.
